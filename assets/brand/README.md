# Between the Lines brand mark

## Master files

- `between-mark-color.svg`: primary mark for light backgrounds.
- `between-mark-color-dark.svg`: primary mark for dark backgrounds.
- `between-mark-black.svg`: one-color mark for light backgrounds and print.
- `between-mark-white.svg`: one-color reversed mark for dark backgrounds and print.
- `png/`: transparent raster exports for platforms that cannot use SVG.

## Palette

- Ink: `#0B0F14`
- Ice: `#F4F4F5`
- Blue: `#2563EB`
- Red: `#EF4444`

Use SVG whenever possible. Keep clear space around the mark equal to at least the puck width, and do not close the intentional gaps between the shafts, blades, or puck surfaces.
